## Featured project

### [multicpa-landing](https://github.com/DimaManko/multicpa-landing/tree/develop)

A team landing page built in the Campfire Middle Frontend bootcamp with React, TypeScript, Vite, Feature-Sliced Design, SCSS Modules, and GSAP.

What I worked on:

- Benefits section, including GSAP enter animations and marquee control (desktop through the snap-scroll engine, mobile through IntersectionObserver)
- 404 page
- Routing with React Router loaders and locale redirects
- Internationalization with i18next and locale resolving
- Project documentation
- Git-flow setup (`master` / `develop` / feature branches, branch protection)
